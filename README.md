# book
STORYLEARN — STUDY WEBSITE

HOW TO OPEN
1. Download StoryLearn_Professional_Website.zip.
2. Right-click the ZIP file and choose Extract All.
3. Open the extracted StoryLearn_Professional folder.
4. Double-click index.html to open it in Chrome or Edge.
5. Keep the assets folder beside index.html; do not move the image files out of it.

WHAT IS INCLUDED
- Calm, pleasant sage-green, cream and soft-lavender visual theme.
- Java Programming and Web Technology, each arranged into units and concepts.
- Story-based lessons, code examples, exam notes and revision tips.
- Four supplied Java illustrations placed after the matching story explanation.
- Ten-question quiz per concept, immediate feedback, scores and a local progress dashboard.
- Editable Student Profile with name, course, college, semester, optional email, learning goal, and study plan.
- Profile details and quiz progress saved locally in the same browser.
- Responsive layout for laptop and mobile screens.

NOTES
This is a front-end website and can run locally without installing anything. Quiz progress is saved in the browser on the same device. It does not have an online account or server backend.
